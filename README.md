# إيجارات كرم مول

نظام متابعة عقود المستأجرين والمطالبات والدفعات ومراحل التحصيل — كرم مول.

- الواجهة: صفحة واحدة `index.html` منشورة على GitHub Pages.
- قاعدة البيانات وتسجيل الدخول: Supabase (`supabase/1_schema.sql` ثم `supabase/2_seed.sql`).
- الصلاحيات: جدول `app_users` — مدير / محرر / مشاهد، ومحمية بـ Row Level Security.
- الإعداد: `config.js` (رابط المشروع والمفتاح العام anon).
